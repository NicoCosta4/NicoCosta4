# Nicolás Costa Fraga

**Bioinformatician · PhD in Molecular Medicine**
Santiago de Compostela, Spain · Open to remote work

I turn multi-omics data into clinically useful results. For the last six years I have been building analysis pipelines for DNA methylation, NGS and liquid biopsy data in cancer research at the Epigenomics Unit of IDIS (Santiago de Compostela). I'm now also focusing on building tools that make this kind of analysis easier to run, reproduce and share.

### What I work on

- **DNA methylation** — Illumina arrays (450K/EPIC), WGBS and RRBS
- **NGS data analysis** — targeted panels and whole-exome sequencing
- **Liquid biopsy** — cfDNA fragmentomics and biomarker discovery
- **Statistics & machine learning** — diagnostic and predictive models

### Tech stack

R / Bioconductor · Python (pandas, scikit-learn) · Bash · Linux / HPC (SLURM) · SQL · Git · Docker / Singularity
